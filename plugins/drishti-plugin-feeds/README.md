# The feed connector

Plugin `feed` (`plugins/drishti-plugin-feeds`): real overnight rates, reference FX and a government curve beside a pack's own data.
The `market-data` pack names five connectors on it, each **off** until its variable is `true`.

## What it reads

Each connector fetches one feed (`feed`) at start and every `refresh-minutes` (60), parses the answer into dated observations per
entity and holds them in memory; every read, type-ahead and dated read is answered from there. A failed fetch keeps the last good
data and says so in health. It is **dated**: a read on a date takes the newest observation on or before it, and the document's
`businessDate` is that observation's date. History is the publisher's window of the last fetch (60 fixings, 90 days of FX, one to two
months of curve), not an accumulation.

| `feed` | Connector (market-data pack) | Switch | Kind | Ids |
|---|---|---|---|---|
| `nyfed-sofr` | `nyfed-sofr-feed` | `DRISHTI_FEED_NYFED_SOFR` | `rate-fixing` | `FIX-SOFR-NYFED` |
| `ecb-estr` | `ecb-estr-feed` | `DRISHTI_FEED_ECB_ESTR` | `rate-fixing` | `FIX-ESTR-ECB` |
| `ecb-fx` | `ecb-fx-feed` | `DRISHTI_FEED_ECB_FX` | `fx-spot` | `FX-EURUSD-ECB` … ten pairs |
| `us-treasury` | `us-treasury-feed` | `DRISHTI_FEED_US_TREASURY` | `ir-curve` | `CRV-USD-UST` |
| `fred` | `fred-feed` | `DRISHTI_FEED_FRED` and `FRED_API_KEY` | `rate-fixing` | `FIX-FRED-<series>` (`DRISHTI_FRED_SERIES`, default `DGS10,DFF`) |

## Data structure

**Id rule:** every id names its publisher (`FIX-SOFR-NYFED`, `FX-EURGBP-ECB`, `CRV-USD-UST`, `FIX-FRED-DGS10`), so a feed never
collides with the pack's own data (`FIX-SOFR`, `FX-EURUSD`). **Field names are camelCase** (a known gap: the shipped packs' documents are
UPPER_SNAKE, `indexId` ↔ `INDEX_ID`, `fixings[].ratePct` ↔ `FIXINGS[].RATE_PCT`; the full document maps every field).

- **`rate-fixing`** (SOFR, €STR, FRED): `indexId`, `name`, `latest`, `administrator`, `tenor`, `currency`, and `fixings[]`: up to the
  20 newest observations on or before the date, newest first, each `{date, rate, ratePct, volumeBn}` (`rate` a fraction to six
  decimals; `volumeBn` for SOFR only).
- **`fx-spot`**: `pair`, `pairName`, `mid`, `bid` = `ask` = `mid` (a reference rate, not a traded price), `change1d` (`mid / previous mid
  - 1`), `spotDate`, `history[]` of up to 30 `{date, mid}` oldest first, and `conventions {base, quote, fixing, note}`.
- **`ir-curve`**: `curveId`, `currency`, `curveType`, `index`, `tenY` (10Y par yield), `slope2s10s` (bp), `asOf`, `points[]` of
  `{tenor, maturity, instrument, quote, zeroRate, df}` (`zeroRate` is the par yield, not a bootstrapped zero), `forwards[]`, `source`.

```json
{ "indexId": "FIX-SOFR-NYFED", "name": "Secured Overnight Financing Rate (NY Fed)", "latest": 0.0388, "currency": "USD",
  "fixings": [ { "date": "2026-09-29", "rate": 0.0388, "ratePct": 3.88, "volumeBn": 2967.0 }, … ] }
```

## Examples

```yaml
# config/connectors/nyfed-sofr-feed.yaml (written from the market-data pack's template at first start)
plugin: feed
enabled: "${DRISHTI_FEED_NYFED_SOFR:false}"
kinds: [rate-fixing]
settings:
  feed: nyfed-sofr
  refresh-minutes: 60
  stale-after: 4d
```

Without internet, point `url` at a mirror (`url: file:///srv/mirror/sofr-last-60.json`, or an `https://` mirror with `tls.ca-file`);
for `us-treasury` and `fred`, `url` is a comma list matching the months or `series`. There is no hand-written example file and no
loader: the files come from the pack's templates (`drishti.py connector list`).

## Troubleshooting

- `FIX FIX-SOFR-NYFED` → `DRS-1001`: the feed is off; set its variable to `true` (or `enabled: true` in its file).
- `DOWN: ConnectException`, `HttpConnectTimeoutException`, `HttpTimeoutException`: no outbound internet or an unconfigured proxy;
  allow the publisher's host, set `proxy.url`, or use a mirror.
- `DOWN: IllegalStateException: HTTP 400 from api.stlouisfed.org`: no or bad `FRED_API_KEY`, or a misspelt series.
- `DOWN: JsonParseException …` / `SAXParseException …`: an HTML page instead of data (a proxy login page, a changed endpoint).
- `DOWN: the feed returned no data (serving the last data)`: the last refresh parsed nothing; earlier data is still served.
- `failedToStart`: `unknown feed 'x'`: use `nyfed-sofr`, `ecb-estr`, `ecb-fx`, `us-treasury` or `fred`.
- Live shows yesterday's SOFR: expected; SOFR and €STR are published the next business day.

Every health text is in the full document, section *Failure and recovery*.
