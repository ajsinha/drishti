# The iceberg connector

Plugin `iceberg` (`plugins/drishti-plugin-iceberg`): the Delta connector's design applied to Apache Iceberg, the table format behind
Snowflake's Iceberg tables, AWS Glue, Dremio, Trino and Apache Polaris. Built for a million trades a day kept for seven years. For
tables someone else designed, use `iceberg-external`.

## What it reads

A data domain is a folder (`<root>/<domain>/<kind>`, `catalog: hadoop`, the default) or a REST catalog's namespace (`catalog: rest`
with `uri`, `warehouse`, `credential`), and each kind is one Iceberg table (or `table.<kind>` when its name differs). A table can also
be named by its metadata file (`metadata-location.<kind>`), and a table copied elsewhere is read with `relocate`. Two engines: `native`
(drishti-iceberg, no Hadoop, the default) and `library` (Apache Iceberg Java over Hadoop; also `abfs://`, `gs://`, `hdfs://`). It
reads position and equality deletes and answers *known at* from older snapshots. It never writes; `tools/load-iceberg.sh` does.

## Data structure

```
<root>/trading/trade/
  metadata/v12.metadata.json, version-hint.text, snap-….avro, …-m0.avro     schema, snapshots, manifests
  data/business_date=2026-09-30/2026-09-30-0000N-<uuid>.parquet             a partition per day; files of 250,000 rows
```

| Column (field id) | Type | Content |
|---|---|---|
| `id` (1) | string, required | the entity id (`MX-20000001`) |
| `doc` (2) | string | the whole JSON document, exactly what a view shows |
| `business_date` (3) | date, required | the identity partition |
| promoted fields (`TRADE_ID`, `PORTFOLIO`, …) | string or double | copies of `layout.<kind>.columns`; `LEGS.CURRENCY` is `LEGS__CURRENCY` |
| vector fields (`PNL`, `SCENARIO_PV`) | `list<double>`, optional elements | `layout.<kind>.vectors` (2.9.5): the numbers out of `doc`, which keeps `{"$vector": "PNL"}`; a missing element is null, never 0 |

- **Id rule:** `id`, unique per business day; sort order `id ASC`, so manifest and footer bounds let a read skip all but one row group.
- **Table properties the loader sets:** `format-version` 2, `write.parquet.row-group-size-bytes` 1048576, zstd compression, no
  metrics for `doc`, full metrics for `id`, `drishti.layout.file-rows` 250000.
- **Nested data** stays inside `doc`; small kinds (curves, counterparties) need no layout.
- **Disk caches** (2.9.5): `<data>/cache/<connector>/idmaps/<kind>/<date>@<fingerprint>.idmap` (memory-mapped id maps) and
  `<data>/cache/<connector>/docs` (documents read, RocksDB), kept across restarts; `id-map-disk.enabled`, `doc-disk-cache.enabled`.

## Examples

```yaml
# config/connectors/trade-endur.yaml (the same as config/connectors.examples/iceberg/trade-endur.yaml)
plugin: iceberg
kinds: [trade]
settings:
  domain: trading
  catalog: ${DRISHTI_ICEBERG_CATALOG:hadoop}
  root: ${DRISHTI_ICEBERG_ROOT:${drishti.data.dir:./data}/iceberg}
  uri: ${DRISHTI_ICEBERG_URI:}
  warehouse: ${DRISHTI_ICEBERG_WAREHOUSE:}
  credential: ${DRISHTI_ICEBERG_CREDENTIAL:}
  layout.trade.columns: TRADE_ID,SOURCE_SYSTEM,PRODUCT_TYPE,CURRENCY,QUANTITY,COUNTERPARTY,PORTFOLIO
```

For Polaris or Snowflake Open Catalog set `catalog: rest`, `uri`, `warehouse`, `credential: "${POLARIS_CLIENT_ID}:${POLARIS_CLIENT_SECRET}"`
and `scope`; for AWS Glue's REST endpoint `catalog.rest.sigv4-enabled: "true"`, `catalog.rest.signing-name: glue` and
`catalog.rest.signing-region`. Load with `tools/load-iceberg.sh ./data/iceberg` (`--trades N --days D` for a generated book) or
`tools\windows\load-iceberg.ps1`.

## Troubleshooting

- `DOWN: cannot reach …`: the root folder, bucket or catalog namespace is not reachable; check `root`/`uri`, credentials, `s3.*`.
- `DOWN: no Iceberg tables under …`: nothing loaded in that domain, or the wrong `domain`/`namespace`.
- `UP (not laid out as the pack declares: trade (12 of 19 columns) …)`: reload, or `IcebergMaintenance --columns`.
- `DEGRADED: cannot read trade: its metadata names files under <old folder> that are not there …`: the table was moved after it was
  written; read it with `engine: native` and the `relocate` the message gives, quotes and all.
- `UP (relocate is read by engine: native only; engine: library ignores it)`: set `engine: native`.
- Single reads slow with `daysWithDeletes` above 0: many equality deletes; `IcebergMaintenance --relayout`.

Every health text is in the full document, section *Diagnosing*.
