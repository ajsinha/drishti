# The yfinance connector

Plugin `yfinance` (`plugins/drishti-plugin-yfinance`): a connector that is code, not a store, like `news`. Each document is computed
from `query1.finance.yahoo.com/v8/finance/chart` when it is asked for.

> **Internal use only.** The endpoint is not a supported API and can change or disappear without notice. Free price feeds forbid
> redistribution: do not run this connector in production, do not redistribute or commit what it returns, and do not build on it. Use
> a licensed feed for real market data. It is **off as shipped**, and the ticker you ask about leaves your network to Yahoo when it is on.

## What it reads

For `QUOTE-AAPL` it sends one GET for the symbol with `range` (6mo) and `interval` (1d), parses the chart answer defensively, works
out the price, change and ranges, and caches the answer per symbol for `cache-ttl-seconds` (60) in a cache of `cache-max-symbols`;
concurrent reads of one symbol share one call. Nothing is fetched at start. Undated, not live; type-ahead offers only symbols asked
for since the start. Two connectors use it: `yfinance` (news-and-markets pack, kind `quote`, `DRISHTI_YFINANCE_ENABLED`) and
`us-equities-prices` (us-equities pack, `id-prefix: PX-`, kind `price-history`, a year of daily bars,
`DRISHTI_US_EQUITIES_PRICES_ENABLED`). In offline mode it never starts.

## Data structure

**Id rule:** `id-prefix` + symbol, `QUOTE-<symbol>`, the symbol 1 to 15 letters, digits and `. ^ = -` (`QUOTE-BRK-B`, `QUOTE-^GSPC`,
`QUOTE-EURUSD=X`), upper-cased. Anything else is not held and never sent; a symbol Yahoo does not know (404) is not held, cached for the TTL.

The document, from `GET /api/v1/entities/quote/QUOTE-AAPL/raw` against the test fake (history shortened):

```json
{ "QUOTE_ID": "QUOTE-AAPL", "SYMBOL": "AAPL", "NAME": "…", "EXCHANGE": "NasdaqGS", "CURRENCY": "USD", "INSTRUMENT_TYPE": "EQUITY",
  "PRICE": 204.3, "PREVIOUS_CLOSE": 202.6, "CHANGE": 1.7, "CHANGE_PCT": 0.839, "DAY_LOW": 201.9, "DAY_HIGH": 205.4,
  "FIFTY_TWO_WEEK_LOW": 140.1, "FIFTY_TWO_WEEK_HIGH": 230.5, "VOLUME": 51234567.0, "MARKET_CAP": null,
  "MARKET_STATE": "UNKNOWN", "AS_OF": "2026-10-20 10:13 America/New_York",
  "HISTORY": [ { "DATE": "2026-09-21", "OPEN": 182.0, "HIGH": 183.0, "LOW": 181.0, "CLOSE": 182.0, "VOLUME": 1000.0 }, … ],
  "DAY_RANGE": "201.90 – 205.40", "FIFTY_TWO_WEEK_RANGE": "140.10 – 230.50", "HISTORY_RANGE": "6mo", "INTERVAL": "1d",
  "PROVENANCE": { "FEED": "Yahoo Finance public chart endpoint (unofficial)", "CACHED_FOR": "60 s",
                  "TERMS": "Sample and internal demonstration use only; not for production or redistribution" } }
```

- `PRICE` is `meta.regularMarketPrice`, else the last close; `CHANGE_PCT` is a percent (`0.84` means 0.84 %).
- `HISTORY[]`: one bar per timestamp of `indicators.quote[0]`; a bar without a close is skipped; dates in the exchange's zone
  (`yyyy-MM-dd`, with `HH:mm` for intraday bars).
- Every field but the price is optional (`MARKET_CAP` is usually `null`). Provenance: `live: false`, `businessDate: null`.

## Examples

```yaml
# config/connectors/yfinance.yaml (written from the news-and-markets pack's template, enabled: ${DRISHTI_YFINANCE_ENABLED:false})
plugin: yfinance
enabled: true
kinds: [quote]
settings:
  range: 6mo
  interval: 1d
  cache-ttl-seconds: '60'
```

A pack reads it from a company's `"QUOTE_ID": "QUOTE-AAPL"` with `source: "link($.QUOTE_ID, 'quote')"` (a line over `$.HISTORY`). An
annotated copy is `config/connectors.examples/other/yfinance.yaml`. There is no loader.

## Troubleshooting

- `DOWN: <reason> (tried again on the next request)`: the last call failed; connection failures, timeouts, 429 (Yahoo's rate limit)
  and 5xx are retried `retries` times, and an older cached answer is served if one is held.
- A ticker answers not held: the symbol does not match the rule, or Yahoo does not know it (health stays `UP`).
- `the response is not readable JSON` / `is not a Yahoo chart answer`: a proxy page or a changed endpoint.
- A bad `range` or `interval`, or a number out of range, fails the start with the setting's name.
- The quote panel is *pending* on the first view: Yahoo is slower than `drishti.graph.link-budget` (40 ms).
