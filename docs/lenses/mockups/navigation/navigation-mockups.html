A calmer top bar: all designers and BI in one menu

Three options. Domain menus (Risk here; Markets, World in other distributions) stay as the module manifests draw them. Icon buttons stay right-aligned and unchanged. Dark and light frames, the console theme tokens, no CDN. Each frame has its new menu open.

Domain menus are conditional: Risk is shown only when the banking module is active; other distributions show their own (Markets, World) instead. The rest of the bar is unchanged.
