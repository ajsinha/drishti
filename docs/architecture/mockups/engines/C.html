How it feels

  • The whole cluster on one screen: which node runs what, and how much memory each spends.
  • The last column answers the question people care about: can I use it?
  • Change any node's engine from any node.

Why not recommended as the page

  • Most installs are one server: a matrix of one column is an awkward page.
  • No room in a cell for needs, used by, what it hides or where the switch is set.
  • Best kept as A's Cluster tab, where it is shown when Drishti*net is on.

Worth keeping

  • The matrix itself, as A's Cluster tab.
  • 'Available to people' with the nodes that serve it.
  • The staged-change bar for a change on another node.
