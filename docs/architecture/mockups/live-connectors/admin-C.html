Admin, option C: connector and companion as a pair alternative

Admin → Connectors shows each data connector beside its live companion, with the path a message takes drawn out: broker, checks, live state (or window), over the lake, the next load. Closest to "every data connector can have a live connector" and best for diagnosis; but it is per connector, so trades from six systems are six cards.
