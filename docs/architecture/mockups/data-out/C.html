How it feels

  • Densest and most familiar: sort, filter, page, as on Data loads.
  • Counts answer "is anything wrong?" before any table.

Trade-offs

  • A node down is a row and a count, less visible than A's banner or B's map.
  • Many columns: wide on a phone.

Build

  • Cheapest: the console's table component.
  • Same data as A.
Mock-up. Design, not built: Admin → Data out for the Arrow Flight service (planned, HOW_IT_FITS.md; the questions' recommendations are drawn as if accepted). Every name, address and number is invented for the picture; addresses are the nodes' real LAN addresses, never localhost. Stop ends a stream with a reason the client sees; Revoke ends the token's streams too. The command word DATAOUT is illustrative. Phone width: cards stack, tables scroll in their frame. Open with #light for the light theme.
