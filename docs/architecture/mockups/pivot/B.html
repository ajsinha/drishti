How it feels

  • A terminal: type the view, read the answer, every panel a key away.
  • What-if and the explanation are always beside the grid.

Why not recommended

  • Fast for experts, a wall for everyone else: the grammar must be learnt.
  • The rail takes width from the grid permanently.

Keep from it

  • The command line (already in A's bar).
  • The notebook view of the four steps, as a tab of A's playground.
