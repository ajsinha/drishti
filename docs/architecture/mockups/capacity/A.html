Why?open-heap-mb 0 gives 0.4 × heap − 512 MB − load-threads × 1.6 GB, at least a tenth of the heap: 0.4 × 10,240 − 512 − 3,200 = 384, so the floor 1,024 MB. JVM arguments each with its condition

ArgumentWhen
-Xmx10g / -Xms10galways / a serverWhy?The heap computed above; -Xms reserves it all at start, so RSS is known from day one.
-XX:+UseG1GC -XX:G1PeriodicGCInterval=60000heap under 16 GBWhy?G1 costs less on a small heap; from 16 GB the rule is generational ZGC. The periodic collection returns unused memory.
-XX:MaxDirectMemorySize=256malwaysWhy?Caps direct buffers (the default cap is the heap's size); mapped hot files do not count against it.
-XX:TrimNativeHeapInterval=60000Java 21.0.1+Why?Returns freed native memory to the system every minute.
-Djdk.nio.maxCachedBufferSize=262144alwaysWhy?Stops each thread keeping a large temporary direct buffer after a read.
-XX:NativeMemoryTracking=summaryalwaysWhy?Lets jcmd split native memory by category; a few per cent overhead.
-XX:MaxMetaspaceSize=512malwaysWhy?A ceiling well above the 131 MB measured, so a class leak fails loudly.
-XX:+HeapDumpOnOutOfMemoryError …/dumpsalwaysWhy?A dump under the data folder; the disk line keeps 10 GB for it.
-Xlog:gc*:file=…/logs/gc-%p.log …alwaysWhy?A rotated GC log (5 × 20 MB).
-Djava.io.tmpdir=…/tmp/serveralwaysWhy?Temporary files under the data folder, never in /tmp.
-Ddrishti.open-dates.net-grace-seconds=120alwaysWhy?The safety net never closes a date read in the last 120 s.
MALLOC_ARENA_MAX=2 (environment)Linux onlyWhy?Two malloc arenas, not one per busy thread: about 500 MB less RSS measured.
-XX:+UseCompactObjectHeadersJava 25 only: not addedWhy?Java 21 refuses to start with it; on 25 it saves about 2% of heap.
