Data inbox: option B, a timeline of runs with a side panelalternative

The Inbox tab as a timeline of cycles, newest on top: the next cycle (with Load now), skipped cycles as thin lines, the current run expanded with its steps (claim, duplicates, load table by table, move, tell the server) and its files in inprocess/, and each finished run with its files, tables, dates, versions, rows and rejects. A side panel holds the files waiting, the failures with Retry, and the engine (switch, owner, lock) with the rules, settings and folder links folded away. Each mock-up shows two scenes: a quiet afternoon (one small run done, three files waiting) and a busy one (a 23-minute run of a 6.2 GB scenario archive, two cycles skipped because runs never overlap, Load now answered skipped, ready.all waiting for the next cycle, and one failed file with Retry). Times are the server's, UTC; a run id is its start time and node.

How it feels

  • Tells the story in order: what happened, what is happening, what is next.
  • Every run's files and versions in place: the best view for "what did the 14:50 run do?".
  • The run's steps show where a long run is.

Trade-offs

  • Waiting files, the thing a person most often checks, sit in the side panel (below the timeline on a phone).
  • Quiet days are a column of "nothing ready" (folded into thin lines and filters).
  • Rules and settings are folded: less visible.

Build

  • The cycles and ledger of GET /api/v1/admin/dataload drive the timeline; the run's steps are new in the status.
  • Filters are a plain form; works without scripts.
  • More markup than A; same data.
Mock-up. Design, not built: Admin → Data loads → Inbox (planned, DATA_LAKE_GUIDE.md section 3.1). Every number is invented for the picture. The data comes from GET /api/v1/admin/dataload; Load now is POST …/run, Retry POST …/retry (both loads:write). On a node that is not the owner the tab names the owner and links to it. Phone width: columns stack, tables scroll in their frame, controls are touch sized. Open with #light for the light theme.
