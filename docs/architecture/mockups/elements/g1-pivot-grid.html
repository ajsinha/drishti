Try: drag chips between the wells · ▾ on a Values chip picks its aggregation · ▾ on a Filters chip picks members or a value filter · ▸ on a region header collapses its pivot result columns to the region total · ☰ on a column header opens the column menu (sort, filter, hide, pin, autosize) · right-click a cell for the context menu · drag across cells (or Shift+click) for a range: the status bar shows count, sum, average · E explains the selected cell · arrows move · Enter expands · Ctrl+C copies · Esc clears. ◆ marks a measure that is not additive: every total is the server's own figure for its group.
