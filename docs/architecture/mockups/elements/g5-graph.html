Try: scroll to zoom, drag the background to pan, drag a node to move and pin it · click a node to select it (Shift+click adds), double-click to expand its neighbours · search a name, or give two nodes to Path · switch the layout (force, hierarchy, radial) · group by an attribute (click a group to open it) · size and colour by a measure · filter by type · Explain on a selected node · the table follows the selection and back · export PNG, SVG or the data. In C type help. The dense cluster (Meridian's 1,500 trades, 600 securitisation vehicles, an 800-account community) shows the canvas at a few thousand nodes; the component switches to WebGL above about 50,000. All data is synthetic.
