The genomics sample module's source tree as built (docs/architecture/KERNEL_AND_MODULES.md sections 8.9 and 8.10): the one module layout.
The .dmod content sits at the folder's top, as inside the package; the code is one Maven project under java/, aggregated by pom.xml.
`./mvnw package -pl modules/genomics/java/genomics -am` (or `mvn verify` in the module folder) builds the jar, packs the folder into
java/genomics/target/dmod/genomics-0.1.0.dmod and runs C1–C14.

modules/genomics/
├── module.yaml                                 the manifest                                                  → module.yaml
├── packs/genomics/                             contracts of gene, cohort, sample, variant                    → packs/genomics/
├── console/                                    plugin.yaml (format 2), pages/explorer.html, static/          → console/
├── elements/drishti-genomics/                  the domain Elements library (genomics.lollipop)               → elements/
├── data/                                       needs.yaml and samples/ (two VCF cohorts, gene.jsonl)         → data/
├── docs/                                       README.md, help.yaml, guide.md, tutorial.md                   → docs/
├── tools/make_samples.py                       writes data/samples (seeded)                                  never packed
├── java/
│   └── genomics/                               the Maven project (parent drishti-module-parent)              → java/genomics.jar
│       ├── pom.xml                             drishti-module-maven-plugin: validate, assemble (source: the module folder), conformance
│       ├── src/main/java/org/helixlab/genomics/   GenomicsModule, ModuleConfig, GenomicsData, GenomicsController ...
│       ├── src/test/java/org/helixlab/genomics/   VcfTest, the module's own tests
│       └── target/dmod/genomics-0.1.0.dmod     the build's output (git-ignored)
└── pom.xml                                     aggregates java/genomics (built by the root pom)                never packed
