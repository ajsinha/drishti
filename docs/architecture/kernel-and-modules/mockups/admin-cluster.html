Cell detail · click any cell

A, matrix + detail drawer (recommended). One row per module part and one column per node answers where does what run at a glance; node headers carry role, free memory and health, part labels carry the class and the max-nodes limit, and the drawer explains any cell in words with its one fix (Resync, Clean up) or the link to Deploy. Colour is never the only signal: each cell also says active, drift, leftover or not placed. Weak spot: wide beyond eight nodes; columns then group by role with a count and expand on click.
