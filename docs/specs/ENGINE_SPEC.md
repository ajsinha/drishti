# The Drishti engine specification (moved)

The engine specification, `engine: 1`, lives in the drishti-engine repository, beside the code that implements it and the kit that
proves it: **[spec/1/SPEC.md](https://github.com/drishti-platform/drishti-engine/blob/develop/spec/1/SPEC.md)** (draft 3, amended 2026-11-22: `product` and the licence check, `ENG-1014`; the exact-path option
declared by `forces: exact-path`). The descriptor's JSON Schema is
**[spec/1/descriptor.schema.json](https://github.com/drishti-platform/drishti-engine/blob/develop/spec/1/descriptor.schema.json)**. One home per fact: this file only points there, and section numbers cited in Drishti's
documents (for example "ENGINE_SPEC section 17") are that file's sections. The design behind it, and Drishti's side, is
[../plans/ENGINE_INTEGRATION_DESIGN.md](../plans/ENGINE_INTEGRATION_DESIGN.md).
