Drishti as a house: three options

For the console landing page (Home, sign-in) and HOW_IT_FITS. Pick one; the chosen picture then goes into both.

  • Foundation = the kernel (lakes + connectors, compute, Rachana + BI, security, cluster)
  • Houses = distributions (Risk, Finance; All is the show home)
  • Rooms = modules
  • Front door = the console, one per house
  • Shelves = workspaces: they arrange, never lock
  • Books = screens
  • Pipes = data bindings
  • Buildings on the estate = placement
  • Renovation with a permit = deploy (four eyes)
  • Manager's office = Admin; dashboard by the door = Health
  • Keys = access rights
  • Plug-in room = a .dmod, loaded like a Linux .ko driver
