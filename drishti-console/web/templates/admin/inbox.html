Files dropped in the inbox folder with a .ready marker are loaded into the lake by {{ PRODUCT }} every interval. The columns follow a file's way through the folders: waiting in inbox/, loading in inprocess/<run>/, done in outbox/. Times are the server's. See the Data guide.

Undo a load

Every row a load wrote carries its load id (a load report's loads, or a row's _load_id). Undoing it removes exactly those rows from every table of the lake, one commit per table and date; a load that replaced a date gets the date back as it was. Check first: nothing changes until you confirm with the load id.
