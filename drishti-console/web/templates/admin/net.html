About this page

Several {{ PRODUCT }} servers acting as one: each tells the others, by gossip, which packs and data it serves, and a request that one cannot answer is answered by another, so a person connected to any server sees the same pages. This page is the cluster as the server this console is on sees it. Its settings are the files of {{ node.dir }} (Files tab, or drishti.py net); what gossip learns is kept in peers.json under the server's data folder. The cluster key is never shown here, only whether it is set. See the operator's guide.
