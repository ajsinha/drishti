Caches

{% with tab='caches' %}{% include "admin/_nav.html" %}{% endwith %}

Every cache on this server: where it lives, its size against its limit, its age, its hit rate and the business dates it holds. Purging is safe at any time: the next reads refill from the source. Purge a date drops one business date only (its answers, views, open date, hot files, layers; a connector that cannot purge one date drops everything and says so). Purges run on this server unless whole cluster is ticked; every purge is audited on each member that runs it. Purge all keeps the VaR and exposure hot files on disk (a rebuild reads the lake): purge var.hot-files or exposure.hot-files by name to delete them. From a terminal: drishti.py server caches, … caches purge NAME [--date D] [--cluster], … caches --dates NAME.
