About this page

Bring a large JSON export (an array or JSON Lines, gzipped or not) and turn it into a Delta table that {{ PRODUCT }}'s Delta connector reads: one row per document, the whole document kept (nested lists intact), partitioned by business date and the classifiers you pick. The build runs on this console's machine with the same engine as drishti.py lake build, so a run here and a scheduled run behave the same (lock, summary, run log). Re-running a day replaces that day only. Lake roots this console may write: {{ cfg.roots | join(', ') }} (lakes.roots). See Tools.
