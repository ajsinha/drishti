Datasets

A dataset is the model reports are built on: tables from the packs' kinds, their relationships, measures and row rules. Open one to read its model and run a query.

Every pack kind is already a dataset, and models put datasets in a star: Models and pack datasets.

New table Tables and models are written in Build › Tables & models: a kind, a connector query, a Python table, a model's answer or another table, with a live preview.

No dataset yet. Make a table in Build › Tables & models, or add a *.table.yaml file to the tables folder.
