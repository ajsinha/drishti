Models and datasets

New dataset

A dataset is one table: what one row is, its columns with their meanings, and how it keeps time. Every pack kind is one already. Make one here to keep only some columns or rows of a pack dataset, say what one row is (and which duplicate wins), add columns worked out from others (a formula or a Python item), group it to a coarser grain, or read a SQL query, a Python table or the answer of a model.

    Where does the table come from?

    Want the tables of a pack kind joined, with measures and row rules (a version 1 dataset)? Use the guided tables builder.
