Notebook

Open a model as an extract of the rows you may see (masked columns stay masked), then query it with SQL cells, run by the server as you, and Python cells, run on the server's compute pool. Save the work as a notebook; promote a cell into a Python item or a report draft. To slice and total a table, use the Pivot.

More extracts: join several models

Add other models as extracts of their own. A Python cell reads one as extract("name") (a pandas table of the rows you may see) and joins them. Each is built for you by the server, with your row rules and masks, as the first one is.
