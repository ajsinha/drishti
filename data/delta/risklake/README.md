# The risklake lake

This folder is kept in git with only this file. Loads into the lake `risklake` (the data inbox with `lake: risklake` in a `.ready` file, `drishti.py lake build --lake risklake`, or the parallel loader) fill it, one folder per domain and table. **What is written here is real data and is never committed.** Its lake file, `config/lakes/risklake.yaml`, is created by the first load and stays local; see [DATA_LAKE_GUIDE.md](../../../docs/guides/DATA_LAKE_GUIDE.md).
