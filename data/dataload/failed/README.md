# failed/

Drishti puts a file that could not be loaded here (`failed/<day>/<run>/`) with its `.ready` and `<file>.failed.json`, which says why in words; Retry on Admin → Data loads → Inbox returns it to the inbox. Never edit by hand. This `README.md` is ignored by the inbox.
