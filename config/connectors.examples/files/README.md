# File connector templates

Ready-made connector files for the `file` plugin: one file per banking data domain (`trading`, `reference`, `market`, `risk`,
`credit`, `collateral`), all reading folders under one root that `tools/load-files.sh` fills.

## What it reads

Each file reads `<root>/<domain>/<yyyy-MM-dd>/<kind>.jsonl` (and undated `<root>/<domain>/<kind>.jsonl`) and serves the kinds listed in
it. The reference kinds are read in `effective` mode; every other kind in `snapshot` mode. Nothing is written. The files carry no
promoted columns: add the pack's `layout.<kind>.columns` to a copied file for fast searches.

## Settings

| Setting or variable | Default in the files | Meaning |
|---|---|---|
| `DRISHTI_FILES_ROOT` (`root`) | `${drishti.data.dir:./data}/files` | The folder holding the domain folders |
| `domain` | the file's domain (`trading`, …) | The domain folder under the root |
| `mode.<kind>` | `effective` for the 12 reference kinds | How a date is read |

## Data structure

The root holds a folder per domain, a folder per business date in it, and one JSON-lines file per kind per date; each line is a
loaders' row (`domain`, `kind`, `id`, `date`, `doc`, `columns`) or a plain document (see the
[file connector README](../../../plugins/drishti-plugin-file/README.md)).

| Folder | Files (`<kind>.jsonl`) the connector file serves |
|---|---|
| `trading/<date>/` | `trade` |
| `reference/<date>/` | `counterparty`, `counterparty-group`, `issuer`, `agreement`, `ccp`, `legal-entity`, `book`, `desk`, `trader`, `calendar`, `csa`, `clearing-account` |
| `market/<date>/` | 20 kinds: curves (`ir-curve`, `repo-curve`, `fx-forward-curve`, `credit-curve`, …), surfaces, `fx-spot`, `equity`, `bond`, `rate-fixing`, `correlation-matrix` |
| `risk/<date>/` | `var`, `stress-scenario`, `stress-result`, `frtb-sensitivity`, `pnl-explain` |
| `credit/<date>/` | `netting-set`, `credit-limit`, `exposure-profile`, `cva`, `sa-ccr` |
| `collateral/<date>/` | `collateral-balance`, `margin-call`, `simm` |

## Examples

```bash
tools/load-files.sh                                    # the samples: 1,791 documents x 10 business days into data/files
cp config/connectors.examples/files/*-store.yaml config/connectors/
```

Set `DRISHTI_FILES_ROOT` when the folders are elsewhere. `trading-store.yaml` is a single trade connector, while the trading pack routes
`trade` to `trade-endur`, `trade-calypso` and `trade-murex` as a union: save it as `trade-endur.yaml` (and the other two, each with
`union: "true"`), or keep one file and switch the other two off.

## Troubleshooting

- `DOWN: no directory …`: the root or `<root>/<domain>` does not exist; run the loader or set `DRISHTI_FILES_ROOT`.
- A new day is not served: the next rescan (`rescan-seconds`, 30) has not run.
- Searches say `partial: true`: the copied file has no `layout.<kind>.columns` for the field.
